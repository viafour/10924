# Young Adult Via Runtime Sprites

Runtime expects these PNG files in this directory:

- `front.png`
- `side.png`
- `rear.png`

These are temporary young adult Via sprites used until the 6-year-old and 11-year-old Via sprite sets exist.

Source files provided during prototyping:

- `young_adult_via_front.png`
- `young_adult_via_side.png`
- `young_adult_via_rear.png`

The full registry/reference sheet is not used at runtime.
