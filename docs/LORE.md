# Lore

This directory collects the game-facing lore needed to build the 10924 prototype.

These files are not intended to replace the full source documents. They are working development references: concise enough for implementation, deep enough to preserve the world’s identity.

## Current first-game direction

The project is currently focused on **10924: Liberty**, a browser-first isometric narrative RPG centered on Via Four.

The initial playable focus is:

- Via Four as the primary character
- dedrix transformation as the signature mechanic
- the Great War as the historical and playable conflict
- the aftermath of being created, registered, feared, and monitored as a sentient catastrophe-class weapon
- liberty, personhood, and self-definition as core emotional themes

## Lore philosophy

The game should treat lore as environmental truth rather than exposition-first instruction.

Players should learn through:

- places
- architecture
- customs
- fragments
- overheard speech
- rituals
- names
- emotional implication
- mechanical pressure
- transformation constraints
- after-action records and institutional language

The world should feel like it existed before the player arrived and will continue after they leave.

For **10924: Liberty**, the player should feel that Via Four is not simply powerful. She is a person whose body, history, and classification have been shaped by systems that repeatedly tried to define her before she could define herself.
